# Modelo: ATS compacto

## Quando usar

Use quando o candidato precisa tentar caber em uma pagina ou quando a candidatura exige um arquivo muito curto. Nao e o modelo principal quando ha experiencias e projetos importantes para preservar.

## Estrutura

1. Nome
2. Linha de contato: email, telefone, cidade, pais
3. Links: LinkedIn, GitHub e portfolio em URL completa
4. Objetivo
5. Resumo profissional
6. Competencias
7. Experiencia profissional
8. Projetos
9. Formacao
10. Certificacoes e idiomas, se existirem

## Regras do template

- Uma coluna.
- Fonte Arial 10 pt no corpo.
- Secoes em caixa alta, sem icones.
- Margens compactas, mas nao menores que 0.5 pol.
- Bullets simples com hifen para preservar texto em parsers antigos.
- Conteudo limitado para evitar passar de uma pagina sem cortar informacao critica.

## O que nao fazer

- Nao usar sidebar.
- Nao usar tabela para alinhar datas.
- Nao usar icones de email, telefone ou links.
- Nao esconder links em texto ancorado; manter a URL visivel.
