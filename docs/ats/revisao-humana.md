# Modelo: Revisao humana

## Quando usar

Use quando o envio for por email, networking, recrutador direto ou quando a leitura humana for mais importante que maxima compatibilidade ATS. Ainda evita elementos perigosos, mas usa uma apresentacao um pouco mais confortavel.

## Estrutura

1. Nome
2. Contato e links
3. Resumo profissional
4. Competencias
5. Experiencia profissional
6. Projetos selecionados
7. Formacao e certificacoes

## Regras do template

- Uma coluna.
- Fonte Calibri ou Arial 11 pt.
- Mais espaco entre secoes.
- Headings com peso maior, sem decoracao pesada.
- Links sempre visiveis.

## O que nao fazer

- Nao usar layout editorial com duas colunas.
- Nao usar foto, barra lateral, grafico de skill ou bloco visual.
- Nao sacrificar parsing para parecer mais bonito.
